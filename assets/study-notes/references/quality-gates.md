# 质量红线与交付前自检

交付前的最后一道关。**逐项过，不允许"大概没问题"。**

---

## 一、内容红线（最重要）

> 如果你对某个科目或某个内容实在不理解，并且联网搜索也不能解决，**不要随意生成**。
> 你的教学内容将完全被用于用户的学习，**错误的内容是无法容许的**。

| 项 | 要求 |
|---|---|
| 知识 | 定义、定理、分类、术语准确；不确定就搜、就问、就标注存疑 |
| 代码 | 逻辑正确；标为可运行的必须真的能跑；片段从 `code/` 真实文件摘取并用 `<!-- source: -->` 绑定；伪代码标 `text` |
| 输出 | 只写真实运行结果，并用 `<!-- output: -->` 绑定；没跑过就不要写"输出" |
| 公式 | 推导逐步可查，不跳步；符号先定义后使用；每个等式都有成立条件 |
| 案例 | 数据自洽；算例的每个中间量都能对上 |
| 引用 | 只引用确实知道出处的来源；不编造书名、页码、链接 |

**"标注存疑"的写法**：

```markdown
> <b>*Warning*</b>
> 此处存疑
>
> 关于 $X$ 的取值上限，不同教材有 $n-1$ 与 $n$ 两种约定。本笔记采用 $n-1$（与正文例题一致）。
> 若你的考试用书不同，请以考纲为准。
```

宁可有标注的空白，不要有自信的错误。

## 二、工程红线（脚本可查）

跑 `node <skill>/scripts/check-library.mjs "<根>"`，下列每一项都必须无 error：

- [ ] 命名符合 `Cha_X 章名` / `CX Sec_X 节名.md` / `CX 速查.md` / `CX 测试.md`；没有残留的 `CX-NN 名称.md` 概念文件
- [ ] 所有链接的目标文件存在、锚点对得上标题；无空链接；无指到根目录之外的链接
- [ ] 所有图片文件存在
- [ ] 无 `[[wikilink]]`、`![[嵌入]]`；无 `> [!note]`、`> **Note**:` 旧式标注（warning 也要清掉）
- [ ] 块级公式 `$$` 各占一行
- [ ] 每篇笔记 frontmatter 有 `subject`、`chapter`、`status`、`tags`（`checklist.md` 豁免）
- [ ] 每节练习 3–5 题；`notes_data.js` 里每节 `quiz` 3–5 题
- [ ] `<!-- source: -->` / `<!-- output: -->` 绑定的内容逐行能在对应文件里找到
- [ ] 每章测试满分恰为 100，各题分值之和 = 100，客观题 ≥ 60 分
- [ ] `notes_data.js` 可解析；`file` 路径与真实文件逐字符一致；md 与 js 题目对应
- [ ] 无残留 `{{占位符}}`

需要逐条判断的 warning：篇幅超 800 行、标注块超 20 个、旧式概念编号（`C1-01`）残留、缺 `CX 速查.md`、第 3 章起测试缺 `【回顾 CX】`、写了「真实输出」却没绑定、链接路径含未编码空格。能修的都修；不修的在 `checklist.md` ⑤ 写明原因。

## 三、人工红线（脚本查不了，必须亲自确认）

- [ ] **Typora 实看**：抽 2–3 篇在 Typora 里打开（或请用户打开），标注块标签可见、公式成块显示、表格不乱、链接能点开
- [ ] **门户离线可用**：断网时导航、阅读、测试、速查、进度功能完整（公式降级为源码样式可接受）
- [ ] **启动脚本可用**：双击 `启动学习服务器.bat` 能起服务器并打开浏览器；端口被占用时自动换端口
- [ ] **教学设计**：抽 3 节，对照 `teaching-design.md` 第十一节自查清单（学习目标 ↔ 练习、先猜后看、渐进练习、概念必备元素）
- [ ] **题目可解**：抽 3 道题（含 1 道主观题），题干自洽、答案确实是最优解、解析说清"为什么错"
- [ ] **测试判分**：在门户里做完一套测试，客观题判分正确、主观题能自评、成绩被保存、重测保留最近与最佳
- [ ] **难度渐进**：从第 1 章和第 N 章各读一节，后者确实建立在前面之上，没有用到未讲的概念
- [ ] **间隔复习**：第 3 章起的测试回顾题覆盖至少两个旧章节，且考的是本章会用到的旧知识
- [ ] **速查可用**：速查只含已讲内容，每条能链回正文
- [ ] **风格统一**：所有节笔记骨架一致，符合样章确认时的约定
- [ ] **无装饰性灌水图**：每一张图都确实在解释某件事
